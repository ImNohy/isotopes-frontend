# Страницы приложения

Базовый префикс маршрутов — `/isotopes`. На страницах отображается общая нижняя навигация `NavBar`.

## Общая навигация

`NavBar` содержит ссылки-иконки без текстовых подписей. Видимость пунктов зависит от доступа:

| Ссылка | Иконка | Доступ | Назначение |
|---|---|---|---|
| `/isotopes/feed` | `/icons/home.svg` | `Everyone` | Лента изотопов |
| `/isotopes/catalog` | `/icons/grid.svg` | `Everyone` | Каталог изотопов |
| `/isotopes/draft` | `/icons/circle-plus.svg` | `Auth` | Создание черновика изотопа |
| `/isotopes/auth` | `/icons/profile.svg` | `Guest` | Вход |
| `/isotopes/auth/logout` | `/icons/exit.svg` | `Auth` | Выход, action-маршрут |

## Маршруты

| Маршрут | Страница |
|---|---|
| `/isotopes/feed` | Лента: первый опубликованный изотоп |
| `/isotopes/feed/:isotopeId` | Лента: конкретный изотоп |
| `/isotopes/feed/:isotopeId?next=true` | Лента: следующий опубликованный изотоп, если следующего нет — первый опубликованный |
| `/isotopes/catalog` | Каталог опубликованных изотопов |
| `/isotopes/catalog?maxHalfLifeExponent=N` | Каталог с ограничением по максимальному периоду полураспада |
| `/isotopes/draft` | Создание черновика изотопа |
| `/isotopes/publish` | Публикация черновика изотопа |
| `/isotopes/auth` | Страница входа |
| `/isotopes/auth/logout` | Action-маршрут выхода |

## Страница ленты изотопа

Маршруты: `/isotopes/feed`, `/isotopes/feed/:isotopeId`.

На странице отображаются:

- фоновое видео изотопа с fallback-видео; видео воспроизводится автоматически, зациклено и без звука;
- оверлей;
- мета-блок с лайком, признаком α-распада, периодом полураспада и кнопкой перехода к следующему изотопу;
- название изотопа;
- описание с переключателем «Подробнее» / «Скрыть».

### Кнопки и ссылки

| Элемент | Действие |
|---|---|
| Кнопка лайка `LikeToggle` | Переключает локальное состояние лайка и изменяет счётчик |
| Ссылка «следующий» с иконкой `chevrons-right.svg` | Переходит на `/isotopes/feed/{id}?next=true` |
| Чекбокс в блоке описания | Переключает отображение «Подробнее» / «Скрыть» |

### Поля

| Поле | Тип | Назначение |
|---|---|---|
| Чекбокс описания | `checkbox` | Показ полного или сокращённого описания |

Дополнительно в мета-блоке выводятся:

- признак α-распада: иконка `check.svg` или `cross.svg`;
- период полураспада `T½` в компактном виде, полное значение — в `title`.

## Страница каталога

Маршрут: `/isotopes/catalog`.

Страница содержит форму поиска по максимальному периоду полураспада и список карточек изотопов.

### Форма поиска

Форма отправляется методом `GET`.

| Поле / элемент | Атрибуты | Назначение |
|---|---|---|
| Ползунок `maxHalfLifeExponent` | `type="range"`, `min="-1"`, `max="27"`, `step="1"` | Максимальный период полураспада в виде степени 10 |
| Кнопка «Найти» | `type="submit"` | Отправляет форму с выбранным значением |

Особенности:

- значение `-1` означает отсутствие ограничения и показывает подсказку `T½, макс. (нс)`;
- при значении `N >= 0` отображается `10^N нс.`;
- подписи ползунка: `0 нс.` и `1e27 нс.`.

### Карточка изотопа

Карточка содержит изображение, название, период полураспада и блок лайка.

| Элемент | Действие |
|---|---|
| Ссылка-изображение | Переход на `/isotopes/feed/{id}` |
| Ссылка-название | Переход на `/isotopes/feed/{id}` |
| Кнопка лайка `LikeToggle` | Переключает локальное состояние лайка и изменяет счётчик |
| Кнопка удаления с иконкой `bin.svg` | Отображается только при `isAuthor`; отправляет `POST` на `/isotopes/{id}/delete` |

## Авторизация

### Страница входа

Маршрут: `/isotopes/auth`.

Форма отправляется методом `POST`.

| Поле / элемент | Атрибуты | Назначение |
|---|---|---|
| Логин | `name="login"`, `id="login"` | Ввод логина |
| Пароль | `name="password"`, `id="password"`, `type="password"` | Ввод пароля |
| Кнопка «Войти» | `type="submit"` | Отправляет форму входа |

Особенности:

- поля и кнопка блокируются на время запроса (`isLoading`);
- текст кнопки во время загрузки — «Вход…», в обычном состоянии — «Войти»;
- при ошибке входа выводится сообщение «Неверный логин или пароль»;
- при успешном входе выполняется переход на `/isotopes/catalog`.

### Выход

Маршрут: `/isotopes/auth/logout`.

Отдельная визуальная страница отсутствует: маршрут используется как action-ссылка в `NavBar`. При успешном выходе очищаются пользовательские и изотопные данные, затем выполняется переход на `/isotopes/catalog`. При ошибке выводится сообщение «При выходе произошла ошибка. Попробуйте ещё раз», после чего также выполняется переход на `/isotopes/catalog`.

## Создание изотопа

Создание изотопа представлено двумя состояниями одного процесса:

1. создание черновика — `/isotopes/draft`;
2. публикация черновика — `/isotopes/publish`.

### Состояние 1. Создание черновика

Маршрут: `/isotopes/draft`.

Загрузчик проверяет наличие черновика. Если черновик уже существует, выполняется переход на `/isotopes/publish`.

Форма:

- метод `POST`;
- `encType="multipart/form-data"`.

| Поле | `name` / `id` | Тип | Ограничения и значения |
|---|---|---|---|
| Видео | `video` / `isotope-video` | `file` | `accept="video/*"`, обязательно; есть превью `FallbackVideo` с fallback-видео |
| Фото | `image` / `isotope-image` | `file` | `accept=".png, .jpg, .jpeg"`, обязательно; есть превью `FallbackImage` с fallback-изображением |
| Название изотопа | `name` / `isotope-name` | `text` | `placeholder="Название"`, `minLength=5`, `maxLength=20`, обязательно |

Кнопки:

| Элемент | Действие |
|---|---|
| Кнопка «Сохранить» | `type="submit"`; отправляет форму, создаёт черновик и переводит на `/isotopes/publish` |

### Состояние 2. Публикация черновика

Маршрут: `/isotopes/publish`.

Загрузчик берёт черновик. Если черновика нет, выполняется переход на `/isotopes/draft`. Форма заполняется значениями из черновика.

Форма отправляется методом `POST`.

| Поле | `name` / `id` | Тип | Ограничения и значения |
|---|---|---|---|
| Период полураспада | `halfLife` / `isotope-half-life` | `text` | `inputMode="numeric"`, `pattern="[0-9]+"`, `maxLength=27`, обязательно; значение по умолчанию — `isotopeDraft.halfLife` |
| α-распад | `isAlpha` | `checkbox` | `defaultChecked={isotopeDraft.isAlpha ?? false}`; подпись «α-распад», пояснение «Происходит α-распад» |
| Описание | `description` / `isotope-description` | `textarea` | `placeholder="Описание"`, `maxLength=200`, обязательно; значение по умолчанию — `isotopeDraft.description ?? ''` |

Кнопки:

| Элемент | Действие |
|---|---|
| Кнопка «Опубликовать» | `type="submit"`; отправляет форму, публикует черновик и переводит на `/isotopes/catalog` |

## Общие элементы интерфейса

- `LikeToggle` — кнопка с иконкой сердца и счётчиком лайков; поддерживает горизонтальное и вертикальное отображение.
- `FallbackImage` — изображение с fallback-картинкой при отсутствии `src` или ошибке загрузки.
- `FallbackVideo` — видео с fallback-видео при отсутствии `src` или ошибке загрузки.
- `Field` — обёртка для `label` и `input`.
- `Textarea` — обёртка для `label` и `textarea`.
